# Concept catalogue

All 146 concepts of `concepts/vocabulary.py`, in vocabulary order (= the column order of every checkpoint's `hard_state_head`). Generated by `scripts/concept_catalogue.py` -- re-run it after a rule change instead of editing this file.

Columns:
- **section**: the vocabulary comment the concept sits under; **group**: the coarse group the thesis figures use (`evaluation.common.concept_category`).
- **reads hand**: the rule has at least one condition on the hand (static check of the rule's predicates). `never` = a retired concept whose rule is always false (kept because the order is load-bearing).
- **% true**: share of 21,999 held-out WBridge5 decisions (2000 test deals) where the concept holds for WBridge5's call.
- **hand evidence**: of those, the share where the concept depends on the hand (re-classifying with the 48 probe hands of `nlg.explanation_inputs` changes it). 0% = it only restates the call, so the explanations never cite it as a reason.
- **F1 (own call)**: test-split F1 of the SL independent model's concept head against the rules applied to the model's own call (`runs/evaluation/concepts/concept_quality.json`, support in brackets); **KL if zeroed**: mean KL(pi || pi with the concept set to 0) of the same model, in nats (`runs/evaluation/influence/SL_independent__test.json`). Empty when those files are missing.
